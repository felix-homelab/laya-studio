# Laya Studio runtime.
#
# Two hard dependencies, neither optional:
#
#   * Laya — there is no fallback engine, so the panel cannot serve a decision
#     without it. `laya` pulls its own torch and transformers, which is where
#     almost all of the install size lives (~800 MB of weights on first use).
#   * PostgreSQL — there is no SQLite path. The schema is owned by Prisma's
#     migrations; see prisma/schema.prisma and docs/data-model.md.

# and the MCP SDK's Streamable HTTP transport is what serves it. 2.x is required:
# it renamed FastMCP to MCPServer, which app/mcp/server.py is written against.
mcp>=2,<3
